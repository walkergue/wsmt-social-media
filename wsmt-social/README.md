# WSMT Social Media Prototype

A self-contained browser MVP for WSMT Social Media.

## Open

Open index.html in a browser. No build step or server is required.

## Included

- Landing page for WSMT Social Media
- $1/month recurring membership section
- Stripe-ready subscription language
- User feed and post composer
- Like, comment, share, and bookmark buttons
- Ads dashboard
- Groups and communities
- Marketplace listings
- Business dashboard
- Admin dashboard with MRR, subscribers, reports, and moderation queue
- Mobile responsive design
